# SEO checklist

Everything here is genuinely implemented — no fake claims, no invented
results, no pretend indexing.

## Indexable pages

| Route | Canonical | Notes |
| --- | --- | --- |
| `/` | `campus:landing` | priority 1.0, weekly |
| `/how-it-works/` | `core:how_it_works` | 0.8 monthly |
| `/secret-crush/`, `/mutual-crush/`, `/college-crush/` | `core:*` | 0.7 monthly |
| `/blog/`, `/blog/<slug>/` | `blog:post_list` / post | 0.6 weekly / per-post |
| `/faq/` | `core:faq` | 0.6 monthly |
| `/campus/` | `campus:campus_select` | 0.7 weekly |
| `/safety/`, `/about/`, `/privacy-policy/`, `/contact/`, `/terms/` | `core:*` | lower priority, yearly |
| `/college/<slug>/` | `campus:college_landing` | **not in sitemap**, `noindex` until 5+ members |

Sources of truth for the sitemap: `config/sitemaps.py` (`STATIC_ROUTES`) and
`blog/sitemaps.py`. Both override `get_urls` so `<loc>` uses `SITE_URL`
instead of Django's example.com default — guarded by
`test_sitemap_uses_site_url` and `test_sitemap_never_leaks_campus_or_student_pages`.

## Never indexable

Private/authenticated routes are excluded from the sitemap **and** blocked in
`templates/robots.txt`: `/desk/`, `/secret/`, `/matches/`, `/campus-id/`,
`/notifications/`, `/privacy/`, `/identity/`, `/staff/`, `/join/`,
`/account/`, `/login/`, `/register/`, `/admin/`.

`verify_email_notice` sets `noindex,nofollow`. `CollegeLandingView` sets
`noindex,nofollow` for thin campuses and `index,follow` above the threshold.

## Structured data

- Site-wide `Organization` + `WebSite` (search action → `/campus/?q=`),
  emitted through `config.templatetags.seo.jsonld`.
- Breadcrumbs on every marketing page, the contact page, blog pages and
  college landings (`seo.breadcrumb`).
- `FAQPage` on `/faq/` where every Q&A is also visible on the page — nothing
  exists in markup that a reader can't read.
- `BlogPosting` on each post (headline, description, dates, author, canonical),
  rendered only for published posts.
- No reviews, ratings or aggregate scores are fabricated.

## Meta + sharing

- `base.html` renders `<title>`, unique `meta description`, canonical,
  Open Graph (type/title/description/url/image 1200×630), Twitter
  `summary_large_image`, `theme-color`, and a single merged `robots` tag.
- `/blog/<slug>/` overrides OG to `article` + the post's featured image.
- `static/img/og-default.png` is generated by `scripts/make_og_image.py`
  (run as part of CI/release to regenerate from the SVG in the script).
- Share cards: the college landing includes a copy-to-clipboard join link and
  an OG-ready card. See `docs/growth-plan.md`.

from django.test import Client
c = Client()
for url in ["/", "/blog/", "/faq/", "/secret-crush/", "/mutual-crush/"]:
    r = c.get(url)
    assert r.status_code == 200, (url, r.status_code)
    print(url, "200", len(r.content))
